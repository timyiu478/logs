#### LC-1541. Minimum Insertions to Balance a Parentheses String

##### 2 Stack Approach

Key Idea: Maintain two stacks storing character indices: stack_left for ( and stack_right for ). Actively cancel out valid ( ) ) triplets during the scan by checking if the two most recent right parentheses are adjacent (idx2 == idx1 + 1) and appear after the top left parenthesis.

Intuitions:

* Storing index positions in stacks implies that individual characters have distinct identities and exact spatial dependencies that must be remembered.
* Accumulates invalid states throughout the scan and defers correction to a cleanup loop at the end.

#### Graph: LC-1254. Number of Closed Islands

Key Insight: Any island containing a cell on the grid border (r == 0, r == rows-1, c == 0, c == cols-1) is not closed because it connects directly to the outside boundary.

2-Pass DFS:

1. Run DFS on all boundary 0s to mark any island touching the grid edges.
2. Iterate over the internal grid cells. Any remaining 0 is a guaranteed closed island.
