#### Graph: LC-310. Minimum Height Trees

* The roots that yield minimum heights are the center(s) (either 1 or 2) of the tree
    * 2 root when the longest path length is even
    * 1 root when the longest path length is odd
* How to find the center(s) of the tree: topological tree

#### Hash Table, Binary Search: LC-1930. Unique Length-3 Palindromic Subsequences

* Key Insight: There are only 26 possible letters in the entire string
* Key Idea: Count unique middle characters between the first and last occurrence of each character
* How?
    * Use hash table to record all indices for each character
    * For every potential middle character $y$ that can construct valid $xyx$ pair, use binary search to find the first occurrence of $y$ that is strictly greater than the first occurence of $x$.
        * Validation: Check if that found index is also strictly less than right. If it is, character $y$ lives inside the window
