#### Greedy: LC-2522. Partition String Into Substrings With Values at Most K

1. **Single-Digit Feasibility:**  
Because each character in $s$ ranges from `1` to `9`, a single digit has
a maximum value of `9`. If any individual digit in $s$ exceeds $k$, it is
impossible to form a good partition, and we must immediately return `-1`.

2. **Greedy Choice Property:**  
To minimize the total number of substrings, we should greedily maximize the
length of the current substring. Extending the current substring leaves
a **shorter remaining suffix**. A shorter suffix never requires more partitions
than a longer suffix—it either requires fewer or the same number.

3. **Maximum Digit Bound:**  
The maximum number of digits a valid substring can have is bounded by
`len(str(k))`. We never need to inspect substrings longer than this digit
count.
