#### Dynamic Programming: LC-1220. Count Vowels Permutation

##### DP Approach

Intuitions:

* We can encode `a,e,i,o,u` to 0-4
* We can create a transition graph according to the rules:
    * a <- e, i, u
    * e <- a, i
    * i <- e, o
    * o <- i
    * u <- i, o

DP State:

* dp[i]: number of valid strings of length k ending with vowel i (0-4 mapping).

Base Case:

* dp[i] = 1 (n >= 1)

State Transition:

```
new_dp = [
    (dp[1] + dp[2] + dp[4]) % MOD,
    (dp[0] + dp[2]) % MOD,
    (dp[1] + dp[3]) % MOD,
    dp[2] % MOD,
    (dp[2] + dp[3]) % MOD
]
dp = new_dp
```

Complexity Analysis:

* Time: O(n)
* Space: O(1)

#### Greedy: LC-2914. Minimum Number of Changes to Make Binary String Beautiful

Key Insights:

* s is even length and all substrings are required to be even length -> there is only one way to break down s to 2-length substrings
* If the 2-length substring is 01 or 10, we must change them to 11 or 00 using 1 operation.
    * Because the pairs are strictly disjoint and every valid even-length block can be decomposed into size-2 blocks, local optimal choices (fixing each pair independently) lead to a globally optimal solution without cascading dependencies.
