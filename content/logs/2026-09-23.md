#### Benchmark Mistakes

<details>
<summary>Click to view benchmark code</summary>

```rust
fn my_function(data: &[u32]) -> u64 {
    data.iter().map(|&x| x as u64).sum()
}

fn main() {
    let data: Vec<u32> = (0..1_000).collect();
    let start = std::time::Instant::now();
    for _ in 0..10_000 {
        let _ = my_function(&data);
    }
    println!("took {:?}", start.elapsed());
}
```
</details>

1. Dead Code Elimination (DCE): The compiler optimizes away `my_function` and the loop because the return value is unused and has no side effects.
    - Fix: Wrap output in `std::hint::black_box(my_function(...))` to force the compiler to keep the computation.

2. Constant Folding Inputs: If inputs are known at compile time, the compiler may pre-compute the result during compilation.
    - Fix: Wrap inputs in `std::hint::black_box(&data)` so the compiler treats them as runtime-unknown.

3. Single-Batch Noise: A single execution (even with 10,000 iterations) finishes in milliseconds and is distorted by cold CPU clock scaling, cold caches, branch predictor stalls, and OS context switches.
    - Fix: Run an unmeasured warmup phase first to stabilize CPU frequency/caches, measure dozens of continuous sample runs over several seconds timer.
4. Unrealistic input size.
    - Fix: Benchmark at the sizes you actually use in production if possible.

#### Framegraph

Patterns:

1. Wide flat plateau at the top: A leaf function consuming significant CPU directly.
2. Wide bar with many narrow children: A parent function spending time spread across many helper/callee functions.
3. Deep narrow tower: A deep call stack that executes quickly per call. Usually indicates abstraction overhead or deep recursion.

##### Hardware counter snapshot

* High LLC Cache Miss Rate (> 5%): Suggests data layout issues (poor spatial/temporal locality, cache line bouncing).
* Low Instructions Per Cycle (IPC < 1.5): Suggests the processor is stalling, typically waiting on main memory or pipeline flushes.
* High Branch Misprediction Rate: Suggests unpredictable conditionals in hot loops.
