#### Sliding Window: LC-2401. Longest Nice Subarray

Key Intuition:
1. Nice Subarray Definition: The bitwise AND of every pair equals 0. This means no two elements in the subarray can share a set 1-bit in the same binary
position.
2. Monotonic Property (Bitwise Accumulation): 
   - The bitwise OR mask is monotonically non-decreasing as the window expands to the right (adding elements can only turn bits ON, never OFF).
   - If a conflict occurs with nums[j], we must shrink the window from the left (increment i and remove nums[i] using XOR or bit-clearing) until the conflict is resolved.

Bit Manipulations:

- Window State: `mask` tracks all active 1-bits currently present in the window `nums[i...j-1]`.
- Conflict Check: `mask & nums[j] > 0` means nums[j] shares at least one bit with the current window.
- Window Shrink: `mask &= ~nums[i]` clears the bits belonging to nums[i] when moving the left boundary forward.
