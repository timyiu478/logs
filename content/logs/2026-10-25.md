#### Graph: LC-1145. Binary Tree Coloring Game

Key Insights:

* **Tree Bottleneck / Firewall:** In a tree, there is only *one path* between any two nodes. Picking an immediate neighbor $y$ of $x$ acts as a strict barrier—Player 1 can never cross $y$ to color that region.
* **Bounded Choices:** A node in a binary tree has at most **3 neighbors** (Left Child, Right Child, Parent). Player 2 only ever needs to test these $\le 3$ candidates for $y$.
* **Zero-Sum Majority Partition:** Picking a neighbor splits the tree into two disjoint regions: Player 2's component size ($p_2$) and Player 1's remaining territory ($p_1 = n - p_2$). Player 2 wins if they secure a strict majority ($p_2 > n // 2$).

Key Idea:

1. Build a indirected graph from the binary tree
2. For each neighbor of x, count number of nodes of the neighbor subtree = p2
    1. p1 = n - p2 
    2. return True if p2 > p1
3. Return False
