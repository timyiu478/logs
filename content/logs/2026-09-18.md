#### Choosing Right Scheduling Model

* Model: Blocking Thread
    * Tasks: CPU-heavy workload, Synchronous file I/O, Synchronous vendor library
    * Mechanism: spawn_blocking
    * Why not OS Thread: can integrates with async via .await; these tasks are not long running
    * Why not Asych Task: prevents async worker thread starvation using an elastic pool
* Model: Asych Task
    * Tasks: Concurrent TCP connections, channel read/write
    * Mechanism: tokio::spawn
* Model: Scoped Thread
    * Tasks: data parallelism task over borrored data
    * Mechanism: thread::scope
    * Why: No Arc or heap allocation overhead; No static lifetime constraint
* Model: OS Thread
    * Independent long running background jobs
    * Mechanism: thread::spawn
