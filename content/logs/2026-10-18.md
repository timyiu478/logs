#### Array: LC-2855. Minimum Right Shifts to Sort the Array

Key Takeaways:

* Valid shift array condition: **At most one drop** (`nums[i] > nums[i+1]`)
* Boundary condition: If 1 drop, **`nums[-1] < nums[0]`** must hold true
    * *Why?* Catches edge cases like `[1, 3, 1, 2]` (has 1 drop, but the tail is larger than the head, making a valid rotation impossible).
