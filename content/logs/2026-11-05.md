#### Math: LC-1641. Count Sorted Vowel Strings

* Key Idea: Use the Stars and Bars combinatorial method.
* Why can we use this method:
    1. Lexicographically sorted constraint: Forces a strict mapping of characters to regions (e.g., Region 0 = `a`, Region 1 = `e`, etc.). Once we choose how many of each vowel we want, the sorted sequence is fully determined.
    2. Order indifference: The order in which we pick identical characters doesn't create new unique strings; only the *counts* in each region matter.
