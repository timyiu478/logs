#### Prefix Sum: LC-2171. Removing Minimum Number of Magic Beans

Intuitions:

1. Reducing bags to a size not already present in beans is sub-optimal. The target height for remaining bags will always equal beans[i] for some index in the sorted array.
2. The cost of making all beans "eqaul" to beans[i] = sum of (nums[j] if nums[j] < nums[i], nums[j] - nums[i] otherwise)
3. After sorting beans in ascending order:
    * the cost of making all beans "eqaul" to beans[i]: = sum of (nums[j] if j < i, nums[j] - nums[i] otherwise)
    * the cost formular can be simplified = total sum - (n-i) * beans[i]
