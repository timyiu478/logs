#### Dynamic Programming: LC-935. Knight Dialer

##### Top Down Approach

Intuitions:

* We can use a hash map to store the valid next moves from the current position so that we do not need to traverse all 8 directions
* Recurrsion relation: ways(number, count) =
    * 1 if count == n
    * sum([ways(next_move(number), count + 1)]) otherwise
        * Why sum? Addition is used for mutually exclusive alternatives (e.g., "My next step can be 0, or 3, or 9").
