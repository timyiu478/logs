#### Graph: LC-4085. Find Root of a Colored Tree

Key Insights:

* We can use layered color pattern to find out
    * number of parents of a node
    * number of childs of a node

* Tree structure properties
    * root has 0 parent
    * child has 1 parent -> rejects if parent count > 1
    * node has at most 2 child -> rejects if child count > 2
    * there is only one root in a single connected tree -> rejects if the code found > 1 nodes that have 0 parent
        * this also be caught and rejected by the parent count > 1 check

Key Takeaways:

* a node's validity depends entirely on its immediate neighbors.
