#### Dynamic Programming: LC-698. Partition to K Equal Sum Subsets

**Key Takaways:**

* Target Subset Sum: Each of the `k` subsets must sum to `target_sum = sum(nums) / k`. If `sum(nums) % k != 0`, it's immediately impossible.
* Sequential Bucket Filling: Instead of keeping track of `k` separate buckets, we fill the buckets one by one.
* State Compression via Bitmask: Since `N <= 16`, we use an `N`-bit integer (`mask`) to track exactly which numbers have been used. 
* Implicit Bucket Capacity: If the total sum of all used numbers so far is `S`, the space currently available in the active bucket is uniquely determined by the remainder: `remaining_capacity = target_sum - (S % target_sum)`
