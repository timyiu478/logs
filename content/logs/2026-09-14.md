#### Async Rust

* Runnable Handle: The executor manages tasks indirectly through Runnable handles popped from its scheduling queue
* Confusions I have:
    * Runnable vs Task
* Async Task Prioritization Example
    * **High Priority (Latency-critical):** Network socket frame reading and parsing (Prevents socket buffer backpressure and client timeouts).
    * **Low Priority (Background housekeeping):** In-memory cache TTL eviction (Slight delays only cause temporary memory bloat, not failures).

#### Dynamic Programming: LC-718. Maximum Length of Repeated Subarray

Intuition: Similar to Longest Common Subsequence (LCS), but requires CONTIGUOUS elements (subarray).  Since it must be contiguous, a mismatch immediately resets the length to 0.

State Definiation: `dp[i][j]` = length of common subarray ending at `nums1[i-1]` and `nums2[j-1]`

Recurrence Relation:

```python3
if nums1[i-1] == nums2[j-1]:
    dp[i][j] = 1 + dp[i-1][j-1]
else:
    dp[i][j] = 0
```

Base Case: `dp[i][j] = 0 when i == 0 or j == 0`

Result: `max(dp[i][j]) across all 1 <= i <= M and 1 <= j <= N`
