#### Dynamic Programming: LC-3882. Minimum XOR Path in a Grid

Intuitions:

* **Non-monotonic property:** XOR operations do not preserve order (larger paths can become smaller and vice versa), so greedy/standard shortest-path fails.
* **Path history matters:** We must consider multiple possible XOR values reaching the same cell.
* **Constraint clue:** $0 \le \text{grid}[i][j] \le 1023$ means the max accumulated XOR value is capped at $1023$ ($2^{10}-1$).
* **State / DP Definition:** `dp[i][j]` = a `set` of all possible XOR values to reach cell `(i, j)` (at most $1024$ states per cell).

Key Takeaways:

* DP stores a set of states

#### Array: LC-3880. Minimum Absolute Difference Between Two Values

Intuitions:

* **Neutral elements:** Indices where `nums[i] == 0` can be completely ignored since they form no valid pairs.
* **Symmetry:** Order doesn't matter ($\text{abs}(i - j)$); whether `1` appears before `2` or `2` before `1`, the distance calculation is the same.
* **Greedy tracking:** To minimize `abs(i - j)` between `1` and `2`, an element only ever needs to be paired with its **most recently seen** opposite element. Tracking the last seen indices (`p1`, `p2`) achieves $O(N)$ time and $O(1)$ space in a single pass.
