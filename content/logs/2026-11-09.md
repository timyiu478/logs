#### SortedList: LC-1606. Find Servers That Handled Most Number of Requests

Two Pool Approach:

* Busy Servers (free time, id) maintained by heap
    * why heap? 
        * It provides O(1) time to peak the earliest free time and O(logk) too push/pop busy servers
* Available Servers (id) maintained by sorted list
    * why sorted list?
        * we can add and remove the available server in O(logk) time and search a server in O(logk) time
* Loop Invarient:
    * busy servers and available servers are disjoint
    * busy servers + available servers = all servers
* How this guarantees O(nlogk) time
    * Across all n iterations (requests), a server is pushed into the busy heap at most once per request it handles. That means over the entire algorithm, there are at most n total pushes and at most n total pops. 

Key Questions:

* Time: When do the resource free up?
* Index/Circular Order: Where do we look next if prefered is blocked? 

#### Dynamic Programming, Monotonic Queue: LC-1696. Jump Game VI

##### Recurrence Relation (State Transition)

- **Definition:** `dp[i]` = maximum score achievable starting from index `i` to `n-1`.
- **Formula:** `dp[i] = nums[i] + max(dp[j])` for all $j \in [i+1, \min(n-1, i+k)]$
- **Evaluation Order:** Right-to-Left (Backward DP) since `dp[i]` depends on future states.

##### Data Structure Choice

- **Monotonic Decreasing Deque (storing indices):** 
  - Allows $\mathcal{O}(1)$ retrieval of the maximum `dp` value in the current sliding window `[i+1, i+k]`.
  - Storing indices (rather than values) enables instant spatial distance validation.

##### Deque Invariants (Maintained at every step $i$)

1. **Window Invariant (Time/Space Bound):** 
   - *Condition:* All indices $j$ in the deque must satisfy $j \le i + k$.
   - *Enforcement:* `if q[0] > i + k: q.popleft()` (evict expired elements from the left).
2. **Monotonicity Invariant (Dominance):** 
   - *Condition:* The values `dp[j]` corresponding to the indices in the deque must be strictly monotonically decreasing from left to right.
   - *Enforcement:* `while q and dp[q[-1]] <= dp[i]: q.pop()` (evict dominated, smaller elements from the right before appending `i`).
