#### Heap: LC-2402. Meeting Rooms III

Intuitions:

* This problem is similar to LC-1606. Find Servers That Handled Most Number of Requests which can be solved using two pool approach.
    * room = server, meeting = request

Key Differences vs. LC-1606:

| Feature | LC-1606 (Find Servers) | LC-2402 (Meeting Rooms III) |
| ------- | -----------------------| ----------------------------|
| Selection Rule | Starts at `i % k` and searches circularly | Always picks the **lowest-numbered unused room** |
| Overflow Action | Requests are **dropped** if all servers are busy | Meetings are **delayed** until the earliest room frees up |

Data Structures:

* Busy rooms (Min-Heap): stores `(end_time, room id)` tuples so that we can manage the state change from busy rooms to available rooms efficiently
* Available rooms (Min-Heap): stores `room id` so that we can grab the lowest room id efficiently

#### Sliding Window: LC-2762. Continuous Subarrays

Intuitions:

* This problem is similar to LC-1438. Longest Continuous Subarray With Absolute Diff Less Than or Equal to Limit which can be solved using the monotonic deque approach

Key Idea:

* For any fixed right endpoint r,
    * 1. find the furthest left valid starting position l using the min and max monotonic deques.
    * 2. count how many valid subarrays in this window [l,r] = r-l+1

Why r-l+1:

* If the window [l,r] is valid, then window [l',r] is also valid for l <= l' <= r.
