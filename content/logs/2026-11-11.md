#### LC-1438. Longest Continuous Subarray With Absolute Diff Less Than or Equal to Limit

Intuitions:

* If the subarray[i..j] is invalid, than subarray[i..j'] where j' > j is also invalid.
    * Why? expanding the right boundary only increase or preverse the window maximum and decrease or preverse the window minimum. 
* If the max(subarray[i..j]) - min(subarray[i..j]) <= limit, then the absolute difference between every pair of elements in this subarray <= lmit
    * We can maintain an monotonic increasing deque and an monotonic decreasing deque find the min(subarray[i..j]) and max(subarray[i..j]) in O(1) time
* If the subarray[i..j] is invalid,
    * we should advance i to i' + 1 where nums[i'] == min(subarray[i..j]) when i' < i'' where nums[i''] == max(subarray[i..j])
    * we should advance i to i'' + 1 where nums[i''] == max(subarray[i..j]) when i'' < i' where nums[i'] == min(subarray[i..j])

Loop Invariants:

* Maximum Monotonic Queue: a subset of indices from the current window [l,i]
    * all indexes >= l
    * q[k] < q[k'] if k < k'
    * nums[q[k]] > nums[q[k']] if k < k'
    * nums[q[0]] is the maximum of the current window [l,i]

<summary>Attempts</summary>

Nested Loop:

* TLE -> O(n^2) is not fash enough

```python3
class Solution:
    def longestSubarray(self, nums: list[int], limit: int) -> int:
        ans = 1
        for i in range(len(nums)-1):
            if i > 0 and nums[i] == nums[i-1]:
                continue
            mi = nums[i]
            ma = nums[i]
            for j in range(i+1, len(nums)):
                mi = min(mi, nums[j])
                ma = max(ma, nums[j])
                if ma - mi > limit:
                    break
                ans = max(ans, j-i+1)
        return ans
```

Sorted List + Sliding Window:

* O(nlogn) TC solution only beats 5% solutions

```python3
from sortedcontainers import SortedList

class Solution:
    def longestSubarray(self, nums: list[int], limit: int) -> int:
        ans = 1
        i = 0
        j = 0
        sl = SortedList()
        
        while j < len(nums):
            sl.add(nums[j])
            while i < j and sl[-1]-sl[0] > limit:
                sl.remove(nums[i])
                i += 1
            ans = max(ans, j-i+1)
            j += 1

        return ans
```
