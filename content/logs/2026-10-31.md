#### Stack: LC-2375. Construct Smallest Number From DI String

Key Idea:

* Push numbers $1, 2, \dots, n+1$ onto a stack one by one.
* Whenever we hit an 'I' or reach the end of pattern, pop all elements from the stack into our result array.

Principles:

* Lexicographically Smallest: we must make the most significant digits as smaller as possible

#### Dynamic Programming: LC-3665. Twisted Mirror Path Count

Intuition:

* Constraints: $2 \le m, n \le 500 \implies$ Dynamic Programming is a strong candidate ($\mathcal{O}(m \cdot n)$ states).

DP Breakdown:

* Base Cases:
  * If `i == m - 1` and `j == n - 1`, return `1` (reached the bottom-right corner).
  * If `i >= m` or `j >= n`, return `0` (moved out of grid boundaries).
* Recursion Steps:
  * If `grid[i][j] == 0` (empty cell): 
    * Return $F(i, j+1, \text{right}) + F(i+1, j, \text{down})$
  * If `grid[i][j] == 1` (mirror cell):
    * If entering from `right`: return $F(i+1, j, \text{down})$ (reflected
      down)
    * If entering from `down`: return $F(i, j+1, \text{right})$ (reflected right)
