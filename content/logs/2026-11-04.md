#### Dynamic Programming: LC-688. Knight Probability in Chessboard

Probability:

* Independent Events: Each move decision is independent of previous moves.
  * $P(A \text{ and } B) = P(A) \times P(B)$
* Uniform Probability: The knight chooses one of 8 directions with equal
  likelihood.
  * $P(\text{each move}) = \frac{1}{8} = 0.125$

DP Intuition:

* Overlapping Sub-problems: Evaluating the probability from position `(r, c)` at step `step` will be repeated across different paths.
* Base Cases:
    * If step == k, return 1.
    * If out of bounds at any step, return 0.

#### Hash Table: LC-1540. Can Convert String in K Moves

Intuition:

* If `s[i] != t[i]`, the required shift is: $d = (\text{ord}(t[i]) - \text{ord}(s[i])) \pmod{26}$
* Shift values repeat every $26$ moves because $(d + 26 \cdot c) \pmod{26} = d$.
* Collision Handling (`c`):
  * Let $c$ be the frequency of shift $d$ encountered *prior* to the current index.
  * The actual move index required for the current character is **$d + 26 \cdot c$**.
  * If **$d + 26 \cdot c > k$**, it's impossible, so we return `false`.
