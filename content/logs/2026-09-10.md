#### Sliding Window: LC-295. Find Median from Data Stream

Key Idea: Split the stream into two dynamic halves

```
Max-Heap               Min-Heap
[1, 2, 3, 4]          [5, 6, 7, 8]

Median = (max of max-heap + min of min-heap) / 2
```

The invariants of the heaps:

* every elements of max-heap <= every elements of min-heap
* 0 <= the size of max-heap - the size of min-heap <= 1

#### Min Heap: LC-1851. Minimum Interval to Include Each Query

Key Invariants (Since queries are sorted in ascending order):

* Start-Bound Guarantee: If an interval starts before/at the current query, it will also start before/at ALL future queries.
* End-Bound Guarantee: If an interval ends before the current query, it will also end before ALL future queries.

Optimizations based on these invariants:

* We can safely SKIP pushing an interval into the heap if it ends before the current query.
* We can safely POP expired intervals from the heap permanently, knowing they will never be needed for future queries.

#### Min Heap: LC-373. Find K Pairs with Smallest Sums

Key Idea: think the pairs as a 2D grid where values increase as you move right and down.

The grid for `nums1=[1,1,2]` and `nums2=[1,2,3]`:

```
        1               2               3
1    (1,1) s=2       (1,2) s=3       (1,3) s=4
1    (1,1) s=2       (1,2) s=3       (1,3) s=4
2    (2,1) s=3       (2,2) s=4       (2,3) s=5
```

Min-heap Implemenetation: Push the entire first column `(i, 0)` into the min-heap initially. From then on, whenever you pop (i, j), only push its right neighbor (i, j+1).

- **Sorted Rows:** Each element in `nums1` paired with all of `nums2` forms a strictly non-decreasing sequence.
- **Initial Frontier:** Seeding `(i, 0)` puts the head of every row into the heap, guaranteeing the global minimum is present.
- **Single-Direction Advance:** Advancing only rightwards (`j + 1`) traverses each row sequentially. Because the row heads were pre-loaded, downward movement is implicitly handled.
