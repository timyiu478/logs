#### 01-BFS: LC-2290. Minimum Obstacle Removal to Reach Corner

How prioritize exploring neighboring empty cells first, only moving to cells with obstacles when no free cells are left:

* Use a `deque` instead of a Min-Heap to maintain sorted distance order in O(1) time per edge.
* Append 0-cost transitions (`grid[ni][nj] == 0`) to the left (`appendleft`) to explore immediately.
* Append 1-cost transitions (`grid[ni][nj] == 1`) to the right (`append`) to process after lower-cost paths.

#### Shortest Path: LC-1631. Path With Minimum Effort

Key Takeaways:

* Min-Heap / Dijkstra's Variant:
  * Node State: `(effort, row, col)`
  * Path Distance Metric: `effort(next) = max(current_effort, |height[curr] - height[next]|)`
* Early Termination:
  * The first time the target cell `(m-1, n-1)` is **popped** from the min-heap, the current effort is guaranteed to be optimal.
