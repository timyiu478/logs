#### Math: LC-2849. Determine if a Cell Is Reachable at a Given Time

Intuitions:

* We can calculate the cost of the shortest path (Chebyshev Distance) using start point and end point.
* sx, sy, fx, fy are positive integer -> easy for calculation
* t can be > min distance but the excess time can be "absorbed" except 1 case

Challenges:

* return true if you can reach cell (fx, fy) after exactly t seconds (NOT within t seconds)
    * it is possible to reach cell (fx, fy) if sx == fx and sx == fy and t == 1

#### Monty Hall

* What host action tells us: among the two door we didn't pick, he removed a goat while preserving the prize if it was there.
* So the remaining closed door represent the original **two-door group**!
* Key Question: What simple event determines whether switching wins?
* P(switch win) = P(switch win | first pick is correct) * P(first pick is correct) + P(switch win | first pick is NOT correct) * P(first pick is NOT correct) = 0 * 1/3 + 1 * 2/3 = 2/3

```
Door 1,   Door 2, Door 3
        ------------------
          two door group
```
