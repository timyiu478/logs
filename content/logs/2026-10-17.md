#### Greedy: LC-2966. Divide Array Into Arrays With Max Difference

Sorting Approach:

1. sort the array in ascending order
2. partition array `nums` in ascending order.  2. **Partition** the array into $n // 3$ groups of size 3 using consecutive
   elements (e.g., indices `0–2` for group 1, `3–5` for group 2).
3. Validate: For each sub-array, check the maximum difference: $$\text{sub\_arr}[2] - \text{sub\_arr}[0] \le k$$
   * If any group violates this, return `[]`. Otherwise, add it to the result.

What sorting gives us:

* Numbers that are close in value are forced to sit next to each other
* Adjacent elements form the tightest possible groups
