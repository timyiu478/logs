#### Sliding Window: LC-3321 Find X-Sum of All-Kong Subarrays II

Maintaing two sorted sets allow us to track top x most frequent elements in
a sliding window of size k on `O(log k)` time per step.

* Sorted Set: add/remove/contain in O(log k) time
* Two sets:
    * top-x set: top x elements
    * rest set: elements that are not stored in top-x set
* Maintenance: When the window slides, remove the outgoing element, add the
incoming element, update their frequencies, and rebalance the sets (e.g., move
the highest-ranked element from the rest set into the top-x set if an element
in the top-x set drops out).

#### Concurrency Model: Multi-Processing

* Concept: The OS allocates an entirely new process for every incoming connection.
* Pros: True fault isolation (if one process panics/crashes, others survive).
* Cons: High memory footprint, expensive OS-level context switching, and overhead of Inter-Process Communication (IPC).

Reference: Async Rust, Chapters 1 (Flitton & Morton)
