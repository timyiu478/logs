#### Dynamic Programming: LC-1223. Dice Roll Simulation

##### Bottom Up DP

DP State:

* `dp[t][f]`: number of valid sequences of length `t` ending with face `f` (`0 <= f < 6`)
* `total[t]`: number of valid sequences of length `t` (`sum(dp[t])`)

Base Cases:

* `total[0] = 1` (one 0-length empty sequence; `dp[0][f] = 0` for all `f`)
* `dp[1][f] = 1` for all `f`
* `total[1] = 6`

State Transition (`t = 2..n`):

* `prev = t - 1 - rollMax[f]`
* If `prev < 0`:
  * `dp[t][f] = total[t - 1]` (no run of `rollMax[f] + 1` can fit yet)
* If `prev >= 0`:
  * `forbidden = total[prev] - dp[prev][f]`
  * `dp[t][f] = (total[t - 1] - forbidden) % MOD`
  * **What `forbidden` is:** number of valid prefixes of length `prev` that, when followed by `rollMax[f] + 1` copies of `f`, form a length-`t` sequence ending with `rollMax[f] + 1` consecutive `f`s.
  * **Why `- dp[prev][f]`:** a valid prefix of length `prev` that *already* ends in `f` would form `rollMax[f] + 2` consecutive `f`s (already excluded at earlier steps), so only prefixes not ending in `f` (`total[prev] - dp[prev][f]`) produce a newly forbidden `rollMax[f] + 1` run at length `t`.
* `total[t] = sum(dp[t]) % MOD`

Bottom Up DP:

```python3
class Solution:
    def dieSimulator(self, n: int, rollMax: list[int]) -> int:
        # dp[t][f]: # of valid sequences with length t and end with face f
        dp = [[0] * 6 for _ in range(n+1)]
        # total[t] # of valid sequences with length t
        total = [0] * (n+1)
        total[0] = 1
        MOD = 10**9+7

        # rollMax[i] >= 1
        for i in range(6):
            dp[1][i] = 1
        total[1] = 6

        for t in range(2, n+1):
            for f in range(6):
                dp[t][f] += total[t-1]
                prev = t - 1 - rollMax[f]
                if prev >= 0:
                    # Remove sequences that would end with rollMax[f] + 1 copies of f
                    forbidden = (total[prev] - dp[prev][f]) % MOD
                    dp[t][f] = (dp[t][f] - forbidden) % MOD
            total[t] = sum(dp[t]) % MOD

        return total[n]
```

Top Down DP:

```python3
class Solution:
    def dieSimulator(self, n: int, rollMax: list[int]) -> int:
        @cache
        def roll(s, last_number, c):
            if s == 0:
                return 1
            total = 0
            for i in range(6):
                if i == last_number and c >= rollMax[last_number]:
                    continue
                total += roll(s-1, i, (1 if i != last_number else (c+1)))
            return total
        return roll(n, -1, 0) % (10**9+7)
```
