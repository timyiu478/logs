#### Binary Search: LC-2064. Minimized Maximum of Products Distributed to Any Store

* Iteratively splitting the largest element (e.g., using a max-heap) is not optimal. It fails because the optimal distribution depends globally on the exact number of available stores $n$, not just local maximum reductions.
    * n = 7, quantities = [15,10,10]
    * output quantities distribution: [15,10,10] -> [10,10,8,7] -> [10,10,8,7] -> [10,8,7,5,5] -> [8,7,5,5,5,5] -> [7,5,5,5,5,4,4]
    * ideal quantities distribution: [5,5,5,5,5,5,5]

* Binary Search Approach:
    * Search Space: The maximum products per store ($x$) ranges from 1 to max(quantities).
    * Feasibility Check: Given a target maximum $x$, can we distribute all product types using $\le n$ stores?

```python
def _check(target: int) -> bool:
    stores_needed = 0
    for q in quantities:
        stores_needed += math.ceil(q / target)
        if stores_needed > n:
            return False
    return stores_needed <= n
```
