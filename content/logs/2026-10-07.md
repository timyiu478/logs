#### Stack: LC-1963. Minimum Number of Swaps to Make the String Balanced

* **Stack Elimination:** Removing all naturally balanced pairs `[]` leaves an irreducible sequence of unmatched brackets.
* **Canonical Unmatched Pattern:** The remaining string always reduces to $n$ closing brackets followed by $n$ opening brackets: 

> `] ] ... ]` ($n$ closing) &nbsp;|&nbsp; `[ [ ... [` ($n$ opening)

* Swapping the **first unmatched `]`** with the **last unmatched `[`** fixes **2 pairs** (4 brackets) simultaneously.
  * **Example:** `] ] [ [` $\xrightarrow{\text{Swap index 0 and 3}}$ `[ ] [ ]` (reduces 2 unmatched pairs to 0).
